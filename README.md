# clean-production-audit-10.20

清洁生产智慧审核平台 · 前端设计演示（2026-10-20）。

**本次只有前端设计与交互演示，不包含后端业务开发或真实业务系统部署。** 企业端、政府端、审核流程、行业分析及名录均用于界面与流程展示。

## 运行：双击 CMD 即可

1. 下载本仓库并解压，或使用 `git clone https://github.com/juge-ge/clean-production-audit-10.20.git`。
2. 电脑需安装 **Node.js 22 或更高版本（含 npm）**。
3. 双击项目根目录的 **`启动预览.cmd`**。

启动文件会在首次运行时自动安装依赖（需要联网），随后启动前端并打开浏览器：

**http://127.0.0.1:5178/**

运行期间保留 CMD 窗口；在窗口内按 `Ctrl+C` 可停止服务。若端口已被其他预览占用，请先关闭之前的预览窗口。不要直接双击 `index.html`。

也可在项目目录手动执行：

```sh
npm install
npm run dev -- --open
```

## 功能与菜单

### 企业端

企业详情 → 企业数据中心 → 审核工作台 → 清洁生产审核 OA → 专家库 → 第三方咨询库。

- **企业详情**：查看企业基础资料、历史多轮审核及报告。
- **企业数据中心**：按分类持续上传、查询和维护企业资料。
- **审核工作台**：编写最新一次审核的草稿，维护调研、问题、目标与方案。
- **清洁生产审核 OA**：演示材料提交、版本冻结、反馈修订、方案与验收办理。
- **专家库、第三方咨询库**：搜索、专业方向筛选与详情查看。

### 政府端

监管总览 → 企业数据中心 → 企业审核档案 → 行业水平评估 → 清洁生产审核 OA → 行业报告工作台 → 地方指标建设 → 专家库 → 第三方资讯库。

- **监管总览**：辖区企业、审核状态和统计概览。
- **企业数据中心**：按辖区查看企业持续上传的资料及调研数据。
- **企业审核档案**：检索企业历史报告，只读查看多轮审核档案。
- **行业水平评估**：查看行业分布和六类行业分析，筛选并导出数据。
- **清洁生产审核 OA**：集中查看提交材料，演示正式办理流程。
- **行业报告工作台**：编写报告草稿，引用辖区数据，保存独立版本并导出。
- **地方指标建设**：指标研究、样本测算、企业试评价、专家问卷与成果版本管理。
- **专家库、第三方资讯库**：复用现有名录，提供查询与详情展示。

## 前端演示范围

- 采用 Vue 3、Vite、Naive UI、vxe-table 与 Vue Flow。
- 结构化数据保存在浏览器 `localStorage`，文件保存在 `IndexedDB`，登录会话保存在 `sessionStorage`。
- 数据只在**同一电脑、同一浏览器、同一站点地址**内保留；清理站点数据会清除演示记录，不提供跨设备或多用户实时同步。
- 登录、菜单权限、省市县辖区限制与 OA 办理均为前端模拟，不具备生产环境的服务端鉴权或行政效力。
- OCR、AI 助手与方案优化为提示、规则或样例演示，未接入真实模型与正式计算服务；指标试评价不自动发布地方标准。
- `backend/` 为已有的可选服务骨架，只有健康检查与能力说明；**本次未开发后端，运行前端无需启动它**。

## 项目结构

```text
启动预览.cmd    Windows 一键启动入口
src/            前端页面、组件、演示数据与本地存储逻辑
public/         门户、图片、图标等静态资源
scripts/        门户资源处理脚本
reference/      原始门户与 RuoYi 参考源码、许可证
tests/          业务与浏览器检查
docs/           接口规划及相关说明
backend/        已有可选服务骨架，前端运行不依赖它
```

`node_modules/`、`dist/`、`output/` 及本地源码压缩包不提交到仓库，依赖和构建产物可在本地生成。
